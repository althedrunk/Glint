Glint for Windows x64

GET STARTED
1. Extract the entire ZIP into a folder you can keep, such as Documents\Glint.
2. Open Glint.exe from that folder.
3. Add a Twitch channel. The first time you play video, choose Download in the
   video setup dialog. Glint downloads the video component directly from mpv's
   official GitHub release and checks its checksum. This is a one-time setup.

No .NET SDK, separate .NET runtime installation or administrator access is needed.
Keep the DLLs and Assets folder alongside Glint.exe.

REQUIREMENTS
64-bit Windows 10 version 2004 or later, or Windows 11.
This beta has been tested on Windows 11. An internet connection is required.
Twitch sign-in needs the Microsoft Edge WebView2 Runtime. If it is missing,
install the Evergreen Runtime from Microsoft's official download page:
https://developer.microsoft.com/microsoft-edge/webview2/

ACCOUNT AND SETTINGS
Watching and reading chat do not require signing in.
Settings and protected login details are stored under %APPDATA%\Glint.
The downloaded video component is stored under %LOCALAPPDATA%\Glint\player.
No account details, channel list or settings are supplied with this download.

UPDATES AND REMOVAL
Close Glint before replacing its application files with a newer download.
Your settings are kept separately. To remove the app, close it and delete the
extracted folder. Its settings and downloaded player remain in the locations above.

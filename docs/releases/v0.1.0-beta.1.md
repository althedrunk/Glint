First public Windows beta of Glint.

## Download and run

1. Download **Glint-0.1.0-beta.1-win-x64.zip** from the assets below.
2. Extract the entire ZIP, then open **Glint.exe**.
3. Add a channel. When prompted, choose **Download** to set up video playback once. The component comes directly from mpv's official GitHub release and is checked against its published checksum.

The ZIP includes the .NET and Windows App SDK runtimes. You do not need development tools or administrator access. Keep all extracted files together.

## Included

- Live streams and past broadcasts, tabs and up to four streams in multiview.
- Independent audio controls and flexible chat layouts.
- Twitch, 7TV, BTTV and FFZ chat features, replies, mentions and message history.
- Customisable appearance, chat settings, notifications and shortcuts.

## Requirements and beta notes

- Windows x64: Windows 10 version 2004 or later, or Windows 11. Tested on Windows 11.
- Internet access is required, including the one-time video component download.
- Twitch sign-in requires the [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/).
- The app is unsigned, so Windows may display an unknown-publisher warning.
- Twitch's unofficial APIs can change and affect playback or account features.
- Clip creation requires the separate API login. End-to-end clip creation has not been verified for this beta.

Watching and reading chat work without an account. The download includes no personal settings or account details.

Use the ZIP named above, rather than GitHub's automatically generated **Source code** downloads. Please [report problems here](https://github.com/althedrunk/Glint/issues).

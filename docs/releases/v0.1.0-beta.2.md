Glint for 64-bit Windows, now available as an installer or portable download.

- **Setup.exe:** installs for your Windows account, adds a Start menu shortcut and supports normal uninstall. Existing installed settings are retained.
- **Portable.zip:** extract into a writable folder and open Glint.exe. Settings and player downloads stay in the adjacent Data folder. Keep Data when updating or moving the app.

Supporting runtime files are bundled inside Glint.exe, with licence information in Docs. Neither download requires administrator access or a separate .NET installation. Video playback still offers a one-time download directly from mpv's official release.

Requires 64-bit Windows 10 version 2004 or later, or Windows 11. Tested on Windows 11. Twitch sign-in requires the Microsoft Edge WebView2 Runtime. The beta is unsigned, so Windows may display an unknown-publisher warning.

Downloads include no personal settings or account details. Login tokens are protected for the current Windows account; moving a portable copy to another PC requires signing in again.
